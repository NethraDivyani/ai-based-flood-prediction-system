# 🌊 AI-Based Flood Prediction System

An intelligent flood prediction system developed using Python and Machine Learning techniques to predict potential flood risks based on environmental and weather-related data. The system helps authorities, communities, and disaster management organizations make proactive decisions to reduce flood-related damages.

## 📌 Project Overview

Floods are among the most destructive natural disasters worldwide. This project utilizes Artificial Intelligence and Machine Learning algorithms to analyze historical flood-related data and predict the likelihood of future flood events.

The system aims to:

- Predict flood occurrences using historical and real-time data.
- Improve disaster preparedness and response.
- Provide accurate and data-driven flood risk assessments.
- Support decision-making for disaster management authorities.

## ⚙️ Installation Guide

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/AI-Flood-Prediction-System.git
```

### 2. Navigate to Project Folder

```bash
cd AI-Flood-Prediction-System
```

### 3. Create Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Virtual Environment

Windows:

```bash
venv\Scripts\activate
```

Linux/Mac:

```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Initialize Database

```bash
python init_db.py
```

### 7. Run Application

```bash
python app.py
```
